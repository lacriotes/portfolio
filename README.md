# Ankur Mishra — Graphic Design Portfolio

A lightweight static portfolio website built from the supplied Hotel Rice Palace and NOIRÉ design work.

## Structure

- `index.html` — page content
- `style.css` — responsive visual design
- `script.js` — image lightbox + scroll reveal
- `assets/hotel/` — six Hotel Rice Palace designs
- `assets/noire/` — four NOIRÉ designs

## Run locally

Open `index.html` in a browser, or use VS Code Live Server.

## Deploy

Upload the folder to GitHub and import the repository into Vercel. No build command is required; it is a static HTML/CSS/JS site.

## Portfolio positioning

Hotel Rice Palace is presented as selected social-media/promotional concepts around the local hospitality project. NOIRÉ is explicitly presented as a fictional brand concept. This avoids implying that fictional campaigns or unverified offers were published client work.
